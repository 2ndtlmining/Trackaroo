## Why not Rust (28-Sep)

Pages were already generated in 13–223 ms. The time and bytes go into:
- **Uncompressed HTML:** `/movers` was 1.52 MB raw, but 64 KB once gzipped.
- **Data shipped and never rendered:** 231 KB on `/products`, and 85% zero-change rows on `/movers`.
- **The same scans repeated on every request.**

Phase 2 fixes all three in a few days and keeps 397 vitest tests, the Playwright suites and the SvelteKit UI. A Rust rewrite would be weeks of work to fix a problem the runtime isn't causing.

## Phase 6 outline: redeploy with docker compose

The goal is a one-command, repeatable deploy that keeps the existing prod `db/` and `data/`.

1. Add `docker-compose.yml`:
   - one `trackaroo` service built from the Dockerfile;
   - bind mounts `./db:/app/db` and `./data:/app/data`, the existing host directories, so nothing is copied or lost;
   - `./logs:/app/logs` (from #15);
   - `restart: unless-stopped`;
   - `TZ=Australia/Melbourne`;
   - `env_file: .env`;
   - a `healthcheck` hitting `/healthz` (#9).
2. Add a build stamp: `ARG GIT_SHA` baked into the image, shown in the footer and in `/healthz` (#3).
3. Add `deploy/redeploy.sh`, which runs these steps in order:
   1. `git pull`;
   2. back up the DB **off the container**, to a NAS path (#10), with `quick_check`;
   3. `docker compose build --build-arg GIT_SHA=$(git rev-parse --short HEAD)`;
   4. `docker compose up -d`;
   5. wait until healthy;
   6. `docker compose exec trackaroo python repair_listings.py` (dry run), print it, and ask before `--apply`;
   7. curl `/healthz`, and assert the SHA matches and Umart is listed.
4. First migration from the current `docker run` container:
   1. stop the old container;
   2. copy its bind-mounted `db/` and `data/` paths as they are (confirm them with `docker inspect`);
   3. `docker compose up -d`;
   4. verify.

   Keep the old container stopped rather than removed for one week, so rollback is `docker start`.
5. Turn on the external heartbeat (#9) and the off-host backup schedule (#10).
6. Close #1–#6 after prod is verified, and check the headline cases:
   - the RTX 5060 Ti headline is a 16GB card;
   - there are no ghost listings for the RTX 5090;
   - `/deals` shows no deal under 2% or $10.
